# 短剧模板深度分析

基于 13 个爆款爽剧剧本的结构拆解与创作规律总结。案例只用于分析结构和爽点，不可照抄；正式剧本格式始终以 `SKILL.md` 的输出契约为准。

---

## 一、剧本结构分析

### 1. 长剧结构示例（100 集）

```
1-20集：开篇冲突 + 身份/误会建立
21-40集：矛盾升级 + 感情发展
41-60集：危机加深 + 反派作妖
61-80集：真相揭露 + 打脸反转
81-100集：终极对决 + 大结局
```

这是 100 集项目的比例示例。实际创作必须按计划总集数和当前绝对集号换算前 20%、中 60%、后 20%，不能固定套用上述集号。

### 2. 单集结构（约 1 分钟示例）

```
前15秒：钩子（悬念/冲突/打脸预告）
中30秒：核心剧情（对话+动作）
后15秒：卡点（悬念钩子/反转）
```

用户另行指定单集时长或体量时，以用户要求为准，但钩子、推进和卡点不能缺失。

## 二、13 个剧本类型分析

### 剧本1：《绝色女总是狐妖》仙侠虐恋

**核心设定**：狐妖女总裁 x 人类男员工，千年情缘穿越

**爽点模型**：
- 消极情绪：书生被迫杀爱人
- 烈度放大：全村逼迫、心尖血
- 信息差：观众知道女主是狐妖，男主不知道
- 打脸：男主用自己的心尖血救女主

**情绪曲线**：被逼迫 → 被刺杀 → 穿越千年 → 重逢 → 身份揭露

**经典场景**：
1. 开篇就是高潮：男主拿匕首刺女主胸口
2. 瞬间切换现代：女主成为女总裁，男主是面试员工
3. 身份反差：女主从受害者变成上位者

---

### 剧本2：《顾小姐的拖家赘婿》先婚后爱

**核心设定**：赘婿复仇 + 先婚后爱 + 相爱相杀

**爽点模型**：
- 消极情绪：被岳家看不起
- 烈度放大：父亲去世当天被冷漠对待
- 信息差：观众知道男主是来复仇的
- 打脸：男主掌控公司，岳家求饶

**经典台词**：
```
「之所以娶你，是因为顾家的一切，本来就是我的！」
「让我拜？他没这个资格！」
```

**开篇钩子**：婚礼上父亲去世，新郎反手收回戒指

---

### 剧本3：《将军的毒妻》古装虐恋

**核心设定**：认错救命恩人 + 绿茶陷害 + 虐恋

**爽点模型**：
- 消极情绪：被冤枉推人下楼
- 烈度放大：被掐脖子、被打、被虐待
- 信息差：观众知道女主是救命恩人
- 打脸：真相揭露，绿茶女暴露

**经典套路**：
1. 女主血液有特殊恢复能力
2. 绿茶女冒认救命恩人
3. 男主虐待女主后后悔

**虐点设计**：
- 被掐脖子
- 被打耳光
- 被逼承认没做过的事
- 被关柴房

---

### 剧本4：《娇妻萌宝：总裁请自重》萌宝虐恋

**核心设定**：毒闺蜜陷害 + 萌宝 + 亲子鉴定

**爽点模型**：
- 消极情绪：怀孕被冤枉出轨
- 烈度放大：当众被砸臭鸡蛋、被休妻
- 信息差：观众知道孩子是男主的
- 打脸：亲子鉴定、恶毒女配暴露

**开篇钩子**：女主说「我怀孕了」，男主直接砸照片骂「野种」

**经典台词**：
```
「你怀了野种，还叫我护你？」
「我要让整个江海市的人都知道你苏小优有多无耻。」
```

---

### 剧本5：《娱乐圈顶流机密》娱乐圈喜剧

**核心设定**：经纪人 x 演员 + 复仇 + 成长

**爽点模型**：
- 消极情绪：女主失业想跳楼
- 烈度放大：被经理陷害、被解雇
- 信息差：男主隐藏身份是总裁
- 打脸：男主动用家族力量复仇

**特点**：带喜剧元素，有职场成长线

---

### 剧本6：《妻子的新生》家庭伦理

**核心设定**：无性婚姻 + 出轨 + 觉醒逆袭

**爽点模型**：
- 消极情绪：丈夫冷漠、无性婚姻
- 烈度放大：发现丈夫出轨、被赶出家门
- 信息差：无（现实向）
- 打脸：女主事业成功、渣男后悔

**开篇设计**：从一个可视化事件快速暴露婚姻问题，避免用长篇解释交代关系。

---

### 剧本7：《爱在伤痕累累后》家暴重生

**核心设定**：家暴妈宝男 + 离婚 + 重生

**爽点模型**：
- 消极情绪：被家暴
- 烈度放大：怀孕被逼吃打胎药
- 信息差：观众知道男主隐藏身份
- 打脸：离婚成功、渣男破产

**开篇钩子**：女主穿晚礼服被婆婆刁难，被老公家暴

---

### 剧本8：《河神的新娘》甜宠逆袭

**核心设定**：被祭祀 + 河神救赎 + 逆袭复仇

**爽点模型**：
- 消极情绪：被家人送去祭祀
- 烈度放大：被活活淹死
- 信息差：观众知道女主被河神救了
- 打脸：女主活着回来，家人震惊

**开篇钩子**：花轿里醒来，发现自己被送去祭祀

**经典场景**：家人以为女主死了，女主活着回来

---

### 剧本9：《爱在焚心成焰时》重生复仇

**核心设定**：民国 + 凤凰血脉 + 无限重生

**爽点模型**：
- 消极情绪：被妹妹陷害
- 烈度放大：被打、被虐待、被杀
- 信息差：观众知道女主会重生
- 打脸：每次重生都更强大

**创新点**：无限重生设定，每次重生女主都变得更强

**经典台词**：
```
「宫雪燕，你这个恶毒的女人！」
「事情不是我做的，我是被冤枉的。」
```

### 剧本10：《校霸变校花》身体互换

**核心设定**：身体互换 + 校园 + 互相成长

**爽点模型**：
- 消极情绪：被校霸欺负
- 烈度放大：遭遇人身危险
- 信息差：观众知道两人互换身体
- 打脸：校霸帮校花解决所有麻烦

**开篇钩子**：校花被欺负，校霸英雄救美

**经典台词**：
```
「我是一个打不死的小强，燃烧吧，小宇宙！」
```

### 剧本11：《恋恋红尘》都市言情

**核心设定**：KTV 老板娘 x 外卖小哥，都市暧昧

**爽点模型**：
- 消极情绪：外卖小哥被生活压迫
- 烈度放大：女友家要巨额彩礼、被混混追杀
- 信息差：观众知道女主是 KTV 老板
- 打脸：穷小子被富婆青睐

**开篇钩子**：女主被混混围攻，男主英雄救美

**经典台词**：
```
「这里面有十万块钱，你别嫌弃。」
「我帮你又不是为了图这个。」
```

**特点**：
- 都市娱乐场所背景
- 多条感情线交织
- 有职场斗争（服务员争客户）

### 剧本12：《顾总的饮恨奴妻》豪门虐恋

**核心设定**：未婚妻被陷害 + 杀妹误会 + 主仆反转

**爽点模型**：
- 消极情绪：被未婚夫误会害死妹妹
- 烈度放大：当众溺水折磨、被关押、被羞辱
- 信息差：观众知道女主是无辜的、绿茶女是凶手
- 打脸：真相揭露、男主追妻火葬场

**开篇钩子**：泳池边女主被按入水中，男主冷眼旁观

**经典台词**：
```
「我顾伟当初真是瞎了眼，怎么会想要娶你这种女人。」
「要不是你骗小妙去海边，她怎么可能溺水？」
「虐妻一时爽，追妻火葬场。」
```

**虐点设计**：
- 被按入泳池差点淹死
- 被打耳光
- 被关在房间当奴仆
- 被未婚夫的母亲羞辱

### 剧本13：《我在古代当花魁》穿越商战

**核心设定**：现代女主播穿越 + 青楼逆袭 + 相爱相杀

**爽点模型**：
- 消极情绪：穿越后被扔进青楼
- 烈度放大：被误会下药、被当众羞辱
- 信息差：观众知道女主有现代知识、是被陷害的
- 打脸：利用现代直播手段逆袭、成为头牌

**开篇钩子**：穿越后立刻陷入生存危机，随后被扔进青楼

**经典台词**：
```
「混蛋！你个渣男！吃干抹净就不负责了！」
「想当本王的正妃？你不配。」
「我会帮你重新打造清芳馆，让利润翻倍。」
```

**创新点**：
- 现代直播思维应用到古代青楼经营
- PK 模式、打赏模式、拍卖模式
- 有商战经营线

## 三、开篇设计规律

### 1. 开篇三秒法则

前 3 秒必须出现以下之一：
- 冲突（被打、被骂、被冤枉）
- 悬念（突然穿越、身份曝光）
- 反转（预告结局再回到开始）

### 2. 第一集必备元素

| 元素 | 说明 |
|------|------|
| 钩子 | 开场就是高潮或冲突 |
| 身份 | 确立主角身份和处境 |
| 对立 | 确立反派或矛盾对象 |
| 卡点 | 结尾留悬念 |

### 3. 开篇模板

**模板A：预告式开篇**
```
开场：男主掐住女主脖子：「你个毒妇！」
切回：三天前……
```

**模板B：冲突式开篇**
```
女主：「我怀孕了。」
男主砸照片：「野种？你敢？」
```

**模板C：反转式开篇**
```
女主被送去祭祀 → 淹死 → 突然睁眼在花轿里
```

## 四、爽点设计规律

### 1. 消极情绪来源统计

| 来源 | 出现频率 | 示例 |
|------|----------|------|
| 被冤枉 | 80% | 被冤枉出轨、推人、下药 |
| 被欺负 | 70% | 被家暴、被虐待、被羞辱 |
| 被背叛 | 60% | 被闺蜜陷害、被丈夫出轨 |
| 被抛弃 | 40% | 被赶出家门、被离婚 |

这些比例仅来自样本统计，用于理解常见题材，不是每个新剧本必须照抄的配方。

### 2. 烈度放大技巧

| 技巧 | 效果 |
|------|------|
| 当众羞辱 | 社会性死亡 |
| 身体伤害 | 观众心疼 |
| 亲情背叛 | 情感崩溃 |
| 失去孩子 | 极致虐心 |

### 3. 打脸时机

| 时机 | 适用场景 |
|------|----------|
| 即时打脸 | 小冲突、日常 |
| 延迟打脸（3-5集） | 中等冲突 |
| 终极打脸（最后10集） | 大反派、核心矛盾 |

## 六、剧本结构参考

正式输出必须遵循 `SKILL.md`，不要沿用分析样本中的旧格式：

```text
[1] 内 地点 日
人物：角色A、角色B
△ 一个可见、可执行的主要动作。
角色A（情绪/语气）：「台词。」
```

- 每集常见体量约 1 分钟，用户另有要求时以用户要求为准。
- 每集结尾必须有卡点（悬念）。
- 每 5 集安排一个小高潮。
- 每 10–20 集安排一个大反转。
- 正文不写特写、推拉摇移等镜头指令；镜头语言交给后续分镜步骤。
