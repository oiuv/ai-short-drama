# 短剧结构分析

## 开篇三秒

开场尽快使用一种可见事件建立观看问题：

- 冲突式：关键关系当场破裂、公开质问或利益被夺。
- 悬念式：出现不可能的结果、异常证据或危险倒计时。
- 反转式：先展示高潮的一角，再回到导致它的关键节点。

开篇不是无背景噪声。事件必须同时暴露人物处境，并与全剧核心冲突相连。

## 单集结构

短集不按固定秒数机械切分，但通常包含：

1. 承接：用最短信息恢复上一集未完成的问题；
2. 推进：人物采取行动，产生新阻力；
3. 变化：信息、关系、资源或目标发生不可忽略的改变；
4. 卡点：新结果迫使人物在下一集继续行动。

每集至少完成一个局部因果闭环，不能只有铺垫。

## 连续剧节奏

- 前段：确立主角、欲望、核心对手与规则。
- 中前段：通过局部成功扩大冲突规模。
- 中后段：主角原有策略失效，付出重要代价。
- 高潮段：前期伏笔和人物选择集中兑现。
- 结局段：解决核心问题，展示选择带来的新状态。

建议每三至五集完成一次小高潮，每个小高潮都要改变后续局势；总集数较少时按比例压缩，而不是删掉因果环节。

## 场戏设计

- 一场戏只围绕一个主要戏剧目标。
- 进入场景时尽量晚，完成变化后尽快离开。
- 场内每句对白都应是争取、回避、试探、攻击、保护或交换信息的行动。
- 同一地点与时间连续发生的内容属于同一场，不拆场凑数。
- 场景切换需要带来新的信息、力量关系或视觉空间。

## 钩子类型

- 决定钩子：角色作出无法撤回的选择。
- 信息钩子：关键证据改变已知事实。
- 危机钩子：目标即将失去且时间有限。
- 关系钩子：信任、身份或阵营发生改变。
- 行动钩子：新人物或对手开始采取具体行动。

避免每集都使用“门突然打开”或“某大人物登场”的同一种钩子。

## 可拍摄性检查

- 抽象情绪是否已转换为动作、表情或声音？
- 场景数量是否与制作规模匹配？
- 重要道具是否提前出现并保持一致？
- 群戏是否有明确行动中心，而不是所有人同时反应？
- 高潮是否由人物行动造成，而不是旁白解释？
