# 短剧题材模式

## 情感与关系

### 离婚与追妻

核心是价值错判。先建立一方长期付出却被贬低的事实，再让离开成为主动选择；后续的价值恢复必须来自成长或真相，而不是单纯炫富。

情绪链：被忽视 → 公开决裂 → 独立成长 → 真相出现 → 是否复合的最终选择。

### 先婚后爱与甜宠

核心是关系契约与真实情感冲突。每次靠近都应改变双方判断，并用外部目标检验信任。

情绪链：互不信任 → 被迫合作 → 看见脆弱 → 主动保护 → 公开选择。

## 身份与逆袭

### 赘婿、隐藏身份、归来

核心是反派错误判断主角价值。隐藏身份只能解释资源来源，真正的高潮仍应由主角的行动和选择完成。

情绪链：轻视 → 触及底线 → 主角出手 → 身份或能力兑现 → 关系重排。

### 神医、职业高手、特殊能力

先用具体专业难题建立可信门槛，再让主角通过过程展示能力。避免“一句话宣布第一”或没有过程的全员膜拜。

## 复仇与悬疑

### 重生复仇

主角拥有未来信息，但资源、身份或时间仍有限。每次改变过去都会带来新变量，避免机械复刻前世事件。

情绪链：前世失败 → 回到关键节点 → 小规模验证 → 对手察觉 → 双方升级 → 最终清算。

### 证据悬疑

每个反转前至少埋下一个可回看的事实。线索同时承担表层解释与深层解释，揭晓后要改变人物关系或行动方向。

## 世界与类型

### 都市、职场、家族

冲突围绕真实资源：职位、股权、合同、名誉、继承和关系网络。权力变化要通过可见事件呈现。

### 古装、权谋、仙侠

称呼、礼制、权力边界和能力规则必须一致。角色不能使用超出身份的命令权；法术或特殊能力必须有代价和边界。

### 喜剧

笑点来自人物目标相撞、信息错位和行为升级，不靠角色突然降智。笑点之后仍要推进剧情或关系。

## 选择方法

1. 选择一个主类型作为因果骨架。
2. 最多加入一至两个副类型提供情绪变化。
3. 为每个类型写出独有的观看承诺。
4. 删除只作为标签、无法影响人物选择的类型元素。
