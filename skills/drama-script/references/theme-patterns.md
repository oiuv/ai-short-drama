## 两性主题

### 离婚
**核心爽点**：被嫌弃的一方其实是高价值对象

**经典套路**：
- 妻子嫌弃丈夫窝囊，离婚后发现丈夫是隐形富豪
- 丈夫被岳家羞辱，离婚后身份曝光打脸

**情绪曲线**：
```
被嫌弃 → 被羞辱 → 被抛弃 → 身份曝光 → 追悔莫及
```

### 赘婿
**核心爽点**：入赘者其实身份显赫

**经典套路**：
- 豪门赘婿被当做佣人，实则是顶级家族继承人
- 妻子家族不知他的真实身份，处处刁难

**情绪曲线**：
```
被轻视 → 被羞辱 → 家族危机 → 挺身而出 → 身份揭露
```

### 霸总
**核心爽点**：平凡女孩被顶级男人偏爱

**经典套路**：
- 总裁装穷测试真心，发现真爱后宠妻无度
- 契约婚姻变成真爱，打脸势利女配

**情绪曲线**：
```
被看轻 → 契约关系 → 逐渐沦陷 → 身份揭晓 → 宠爱打脸
```

## 暴力主题

### 战王
**核心爽点**：看似普通人其实是无敌战神

**经典套路**：
- 退役战神隐居当保安，被欺负后展现恐怖实力
- 被当做废物，实则是以一敌万的战王

**情绪曲线**：
```
隐忍 → 被欺负 → 触及底线 → 爆发 → 降维打击
```

### 金手指
**核心爽点**：获得超能力/系统后的逆袭

**经典套路**：
- 获得透视眼/系统/空间，从底层逆袭
- 能看到别人的秘密/属性，信息差碾压

**情绪曲线**：
```
底层挣扎 → 获得能力 → 初试牛刀 → 能力升级 → 无敌碾压
```

### 暴富
**核心爽点**：从穷到富的极速反转

**经典套路**：
- 彩票中奖/遗产继承/比特币暴富
- 曾经看不起他的人跪舔

**情绪曲线**：
```
穷困潦倒 → 被羞辱 → 突然暴富 → 炫富打脸 → 众星捧月
```

## 优势主题

### 官场
**核心爽点**：小人物背后有大靠山

**经典套路**：
- 看似普通科员，实则是大佬之子/女婿
- 被领导打压，一个电话调来省厅领导

**情绪曲线**：
```
被欺负 → 被打压 → 隐忍 → 靠山到场 → 官职碾压
```

### 神医
**核心爽点**：被质疑的医生其实医术通神

**经典套路**：
- 乡村医生被大医院专家看不起，一针救人
- 实习医生被主任羞辱，大佬点名要他看病

**情绪曲线**：
```
被质疑 → 被羞辱 → 危急病人 → 出手救人 → 身份/医术震惊全场
```

### 家族
**核心爽点**：被赶出家族的人其实是最强的

**经典套路**：
- 私生子被家族抛弃，归来已是顶级大佬
- 被逐出家门，多年后收购家族企业

**情绪曲线**：
```
被排挤 → 被赶走 → 独立奋斗 → 功成名就 → 归来碾压
```

## 复仇主题

### 重生
**核心爽点**：带着前世记忆碾压仇人

**经典套路**：
- 被害死后重生到关键节点，提前布局复仇
- 重生到被背叛前，反将一军

**情绪曲线**：
```
前世惨死 → 重生节点 → 提前布局 → 仇人入套 → 复仇成功
```

### 复仇经典模式
**信息差优势**：
- 主角知道未来会发生什么
- 仇人不知道主角已经知情
- 观众享受"我知道你不知道"的优越感

## 设定类型标签

创作时可用以下标签组合构建设定：

### 能力类
- `绑定系统` - 主角有系统辅助
- `异能觉醒` - 主角拥有超自然能力
- `隐藏身份` - 主角真实身份被隐藏
- `金手指` - 主角有作弊能力

### 身份类
- `战神` - 无敌战斗能力
- `神医` - 逆天医术
- `财阀` - 顶级财富
- `权贵` - 顶级权力

### 世界观类
- `末日` - 末世废土背景
- `都市` - 现代都市背景
- `古代` - 古代架空背景
- `玄幻` - 修仙玄幻背景

### 剧情类
- `打脸` - 经典反转打脸
- `复仇` - 报仇雪恨
- `逆袭` - 从低到高
- `宠文` - 宠溺向剧情

---

## 使用方法

1. 根据用户需求选择主题类型
2. 从对应主题中选择经典套路
3. 组合设定类型标签
4. 设计爽点曲线
5. 输出剧本摘要和内容
