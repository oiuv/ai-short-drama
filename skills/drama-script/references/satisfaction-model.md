# 爽点模型详解

## 核心公式

```
爽感 = 消极情绪 × 烈度放大 × 信息差打脸
```

---

## 第一步：找到消极情绪

### 常见消极情绪来源

| 情绪 | 触发场景 | 观众共鸣点 |
|------|----------|------------|
| 被轻视 | 能力被质疑、身份被嘲笑 | 职场被看不起的经历 |
| 被背叛 | 伴侣出轨、朋友背刺 | 感情/信任被辜负 |
| 被欺负 | 职场霸凌、家族排挤 | 弱势被欺压的愤怒 |
| 被误解 | 好心被当成驴肝肺 | 委屈感 |
| 被剥夺 | 利益被抢走、成果被窃取 | 不公平感 |

### 选择原则
选择最能引发大众共鸣的消极情绪，越普遍越好。

---

## 第二步：放大消极情绪（烈度）

### 烈度放大技巧

#### 1. 身份反差
```
普通：被同事看不起
放大：被自己带出来的徒弟看不起，还当众羞辱
```

#### 2. 场合升级
```
普通：私下被骂
放大：公司年会上被当众开除
```

#### 3. 利益绑定
```
普通：被欺负
放大：被欺负的同时，家人/爱人也受牵连
```

#### 4. 时间累积
```
普通：今天被欺负
放大：忍辱负重十年，今天被当众揭穿
```

#### 5. 落井下石
```
普通：被打压
放大：被打压后，对方还要斩草除根
```

### 烈度等级

| 等级 | 描述 | 效果 |
|------|------|------|
| 1级 | 私下被欺负 | 轻微不爽 |
| 2级 | 当众被羞辱 | 明显愤怒 |
| 3级 | 重要场合被打压 | 强烈愤怒 |
| 4级 | 家人/爱人受牵连 | 极度愤怒 |
| 5级 | 生死存亡关头 | 观众情绪拉满 |

---

## 第三步：信息差打脸

### 信息差原理

```
观众信息 > 角色信息 = 期待感
观众知道主角强 + 反派不知道 = 打脸期待
```

### 信息差类型

#### 1. 身份信息差
- 观众知道：主角是战神/财阀/神医
- 反派不知道：以为主角是废物
- 结果：主角身份曝光时，反派崩溃

#### 2. 能力信息差
- 观众知道：主角有金手指/系统
- 反派不知道：以为主角靠运气
- 结果：主角展示实力，碾压全场

#### 3. 关系信息差
- 观众知道：主角和大佬有关系
- 反派不知道：以为主角没关系
- 结果：大佬出场，反派跪下

#### 4. 未来信息差（重生类）
- 观众知道：主角知道未来
- 反派不知道：以为主角是巧合
- 结果：主角提前布局，反派步步踩坑

### 打脸时机选择

| 时机 | 效果 | 适用场景 |
|------|------|----------|
| 即时打脸 | 快速爽感 | 小反派、日常冲突 |
| 延迟打脸 | 期待感积累 | 大反派、高潮场景 |
| 多次打脸 | 持续爽感 | 重要反派、多集剧情 |

---

## 爽点组合模式

### 模式一：层层递进
```
小打脸 → 中打脸 → 大打脸 → 终极打脸
```
适用：主线剧情，多集发展

### 模式二：连环打脸
```
反派A被打脸 → 反派B跳出来 → 反派B被打脸 → 反派C...
```
适用：群嘲场景，一人打一群

### 模式三：追悔莫及
```
被抛弃 → 主角成功 → 对方后悔 → 求复合 → 被拒绝
```
适用：感情线、前任剧情

## 剧本应用示例

### 场景设计
```
[场景] 婚礼现场
[消极情绪] 女主角被当众退婚
[烈度放大] 是她付出一切支持的未婚夫，当着双方父母的面退婚
[信息差] 观众知道旁边那个"服务员"其实是顶级财阀继承人
[打脸] 财阀继承人当众求婚，未婚夫崩溃
```

### 对话设计
```
反派（嚣张）：你这种废物，配得上我？
主角（平静）：是吗。
[观众期待：快打脸快打脸]
[大佬出场]
大佬：谁说他不配？
[打脸完成]
```

---

## 注意事项

1. **爽点密度**：短剧需要高频爽点，不能让观众等太久
2. **情绪节奏**：消极情绪不能持续太长，否则观众会烦躁
3. **打脸力度**：要与之前的欺负程度匹配，越狠的欺负需要越狠的打脸
4. **观众视角**：始终保持观众的上帝视角，不要让观众和主角一起蒙在鼓里
