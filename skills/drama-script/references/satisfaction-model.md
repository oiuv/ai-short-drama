# 爽点模型

## 核心公式

```text
爽感 = 消极情绪 × 烈度放大 × 信息差兑现
```

爽点不是主角突然变强，而是先让观众明确感受到不公、压迫或损失，再让反派基于错误认知做出更过分的选择，最后由主角的真实身份、能力、关系或布局完成有因果的反转。

## 四阶设计

### 1. 情绪锚定

选择最贴近受众经验的一至两种负面情绪：被轻视、被背叛、被欺压、被误解、被剥夺。用具体事件触发，不用旁白宣布情绪。

### 2. 烈度放大

至少选择两种叠加：

- 身份反差：被自己帮助或带出来的人反咬。
- 场合升级：由私下冲突升级到公开羞辱。
- 利益绑定：冲突牵连家人、事业、尊严或生存。
- 时间累积：长期隐忍在关键时刻达到极限。
- 落井下石：主角受损后，对手继续追加代价。

烈度必须服务人物选择。不要为了刺激堆叠与主线无关的伤害。

### 3. 信息差

- 身份差：反派不知道主角的真实身份。
- 能力差：反派低估主角的专业、资源或底牌。
- 关系差：反派不知道主角与关键人物的真实关系。
- 未来差：重生、预知或信息优势让主角提前布局。

观众通常应比反派更早知道底牌，从而产生“等待兑现”的期待。

### 4. 兑现与反转

- 小冲突可以即时兑现。
- 重要对手可延迟三至五集兑现，并在过程中提供局部回报。
- 核心反派需要多阶段瓦解，最终结果与其造成的损失相匹配。

## 常用组合

- 层层递进：小打脸 → 中打脸 → 大打脸 → 终极兑现。
- 连环升级：对手 A 失败 → 更高层对手介入 → 冲突升级。
- 追悔莫及：抛弃主角 → 主角完成成长 → 对方求回 → 主角作出最终选择。
- 提前布局：观众知道主角计划 → 对手连续踩入因果陷阱 → 真相集中揭示。

## 质量检查

- 负面阶段不能长时间没有局部回报。
- 反转必须来自已铺垫的信息，不靠临时出现的大人物解决。
- 主角必须作出选择并承担代价，不能只等外力救援。
- 打击力度与先前伤害相称，不用无关暴力代替戏剧满足。
